**Problem statement**
Problem statement for my prject is simple and easy.Its a mini project which is easy to use.So the problem statement is:
International travelers, students, and professionals frequently struggle to make quick, accurate currency conversions during cross-border transactions. Relying on manual calculations or poorly designed tools often leads to financial errors, budgeting friction, and poor usability—especially when users need to perform multiple consecutive conversions without constantly restarting the program interface. Furthermore, basic programmatic tools often lack a modular, well-structured architecture, making them hard to maintain, expand, or integrate with real-time conversion rates.


**Scope of the project**
1. Core Financial Functionality:
*Multi-Currency Support: Conversion support across major global currencies (e.g., USD, EUR, INR, GBP,many more).

*Bi-directional Calculations: Project have a ability to convert from any supported base currency to a target currency using established conversion factors.

*Continuous Execution Loop: Project have a persistent session model that let the users to calculate multiple conversions back-to-back without restarting the application or re-excuting the project file.

2. Technical Implementation & Architecture
*Top-Down Modular Architecture: Project is decomposed codebase using custom functions for distinct tasks.

*Control Flow & Logic:This project has implemented conditional logic (if-elif-else) to handle currency selection and decision trees.

*Input Validation & Error Handling: Project has design a safeguards against non-numeric inputs, negative monetary amounts, and unsupported currency codes to prevent runtime crashes.

*Mathematical Operations: Project have baisc precision calculation using fundamental Python arithmetic operators.

3. Testing
*Executable Verification: Project has crossed unit-level and end-to-end testing across various user paths to ensure error-free program execution.
